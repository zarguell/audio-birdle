Privacy

Privacy policy

Effective 26 November 2026 · Policy version 2026-11-26

In short

  • The website stores your game progress in this browser. It has no accounts and no server-side profile.
  • Anonymous usage analytics is off by default and loads nothing until you opt in from Settings.
  • Playing through the Discord Activity requires a Discord identity; that part is not anonymous.
  • Bird recordings are loaded from the Macaulay Library and xeno-canto, which see your IP address and browser.

What stays on your device

Audio-Birdle keeps your daily games, stats, region, last-played mode, and dismissed suggestions in this browser's localStorage under the audio-birdle- keys. This data is not uploaded to us.

Clearing site data in your browser erases all of it. Settings also offers “Reset today's games” and “Reset all games and stats”, which delete stored game data but keep your analytics choice.

Anonymous usage analytics (opt-in)

Cloudflare Web Analytics is disabled by default. The beacon script is not part of the page HTML; it is added only after you tick Anonymous usage analytics in Settings. Declining, or never choosing, means zero analytics requests.

What Cloudflare Web Analytics receives after opt-in
Data Why
Page path Which pages people use
Referrer Where visits come from, when the browser sends one
Country Coarse geography from the Cloudflare edge
Browser and operating system Compatibility and device-class trends
Core Web Vitals Page performance

Cloudflare Web Analytics sets no cookies, writes no localStorage entries, and performs no fingerprinting. It reports aggregate traffic only; there is no per-visitor view and no cross-site history. Aggregate data cannot be deleted per person, because it does not identify you.

You can withdraw consent at any time with the same Settings checkbox. Withdrawal removes the beacon immediately, stops future requests, and records your choice with a timestamp in audio-birdle-analytics-consent. That consent record lives outside the game data envelope.

Do Not Track and Global Privacy Control force analytics off: the toggle is disabled and no beacon is loaded even if consent was previously granted.

Discord Activity

Playing through the Discord bot or Activity requires a Discord identity, so that experience is not anonymous. If you never use Discord, none of this applies to you.

Discord data and retention
Data Purpose Retention
Discord id, username, avatar Identify the player and render boards While the app is installed
Daily results (grid, mode, region, score) Public board, streaks, stats command Up to 90 days
Guild and channel id, board message id Keep edits scoped to the right message Up to 30 days
Aggregate usage counters Anonymous launch, completion, mode, and region counts Up to 90 days
Daily player hash Count unique daily players Up to 48 hours; the daily salt is deleted

We do not read or store message content. The bot uses no privileged message intents. Analytics writes in the Activity follow the same consent choice; declining means no counters row for that session.

Run /audiobirdle forget to delete your Discord identity row and every per-user row. Aggregate counters that no longer link to an identity may remain until their retention window ends.

Third parties

Services that can see a request from your browser
Party Role Data seen
Cloudflare Hosting and Web Analytics Requests to the site; analytics only after opt-in
Discord Activity host and bot platform Interaction payloads and channel messages
Macaulay Library at Cornell Lab Audio CDN IP address and user agent for each recording request
xeno-canto Audio CDN IP address and user agent for each recording request

Audio files are hotlinked from Cornell's Macaulay Library and xeno-canto. Your browser requests them directly, which discloses your IP address and user agent to those services; that happens whether or not you enable analytics. We do not sell data and use no advertising or third-party analytics beyond Cloudflare Web Analytics.
