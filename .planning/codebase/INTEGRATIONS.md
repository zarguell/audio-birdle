# External Integrations

**Analysis Date:** 2026-01-15

## APIs & External Services

**Bird Data & Audio:**
- eBird API v2 - Bird taxonomy, species lists, regional observations
  - SDK/Client: Custom Python scripts using `requests` library
  - Auth: API key in `EBIRD_API_KEY` env var
  - Endpoints used: Taxonomy, regional observations, species data
  - Usage: `scripts/ebird-taxonomy.py`, `scripts/ebird-region.py`, `scripts/generate-daily-region-data.py`

- eBird Macaulay Library - Audio recording downloads
  - Integration method: Web scraping via Selenium
  - Script: `scripts/ebird-songdownload.py`
  - Rate limits: Manual scraping process (2-4 hours per region)

## Data Storage

**Databases:**
- None (fully static architecture)

**File Storage:**
- public/data/ - Static JSON data files
  - Files: birds.json, daily.json, regions.json, history.json, daily-subregion-birds.json
  - Generated by: Python scripts in scripts/ directory
  - Served via: Cloudflare Workers static hosting

**Client Storage:**
- Browser localStorage - Game state, user preferences, statistics
  - Managed via: `src/utils/StorageUtils.jsx`
  - No server-side persistence

**Caching:**
- Browser cache for static assets
- No server-side caching layer
