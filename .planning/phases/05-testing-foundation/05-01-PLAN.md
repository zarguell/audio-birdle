Define reusable test fixture strategy for integration tests:

1. **Game State Fixtures:**

   ```javascript
   // Factory function for test game states
   function createTestGameState(overrides = {}) {
     return {
       version: 2,
       dailyGames: {},
       hardModeGames: {},
       stats: { totalGamesPlayed: 0, totalGamesWon: 0, ... },
       ...overrides
     }
   }
   ```

2. **Bird Data Fixtures:**

   ```javascript
   // Sample bird data for testing
   function createTestBird(overrides = {}) {
     return {
       id: "testbird",
       name: "Test Bird",
       scientificName: "Testus birdus",
       order: "Passeriformes",
       family: "Testidae",
       audioUrl: ["http://example.com/audio.mp3"],
       ...overrides,
     };
   }
   ```

3. **Region Data Fixtures:**

   ```javascript
   // Sample region data
   function createTestRegion(overrides = {}) {
     return {
       code: "test",
       name: "Test Region",
       subregions: ["test-sub-1", "test-sub-2"],
       ...overrides,
     };
   }
   ```

4. **Setup/Teardown Patterns:**
   - Using beforeEach/afterEach for localStorage cleanup
   - Using vi.stubGlobal() for browser API mocks
   - Using test.extend() for custom fixtures
