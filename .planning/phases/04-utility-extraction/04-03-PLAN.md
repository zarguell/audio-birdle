Update src/utils/HashUtils.jsx to match Python implementation:

Current hashString function issues:
- hash & hash doesn't ensure 32-bit unsigned correctly
- >>> 0 is good but may not match Python's signed/unsigned handling
- .toString(16) doesn't zero-pad to 8 characters

Fix approach:
- Keep the DJB2 hash algorithm (hash << 5) - hash + char)
- Ensure 32-bit unsigned: use (hash >>> 0) after each iteration or & 0xFFFFFFFF
- Format to 8-char hex: use .toString(16).padStart(8, '0')
- Return lowercase hex string (JavaScript toString is already lowercase)

Update hashString to:
```javascript
export const hashString = (str) => {
  let hash = 0;
  if (str.length === 0) return "00000000"; // Return padded zero hash

  for (let i = 0; i < str.length; i++) {
    const char = str.charCodeAt(i);
    hash = ((hash << 5) - hash) + char;
    hash = hash >>> 0; // Ensure 32-bit unsigned
  }

  // Convert to 8-character lowercase hex
  return hash.toString(16).padStart(8, '0');
};
```

Verify: hashString("test") produces same output as Python hash_string("test")
